# STOOD-X — moved

**→ https://github.com/ari-dasci/S-STOOD-X**

That is the version the paper refers to — *STOOD-X: Explainable out-of-distribution detection via nonparametric statistical testing on large-scale datasets*, Pattern Recognition 177 (2026), [doi:10.1016/j.patcog.2026.113254](https://doi.org/10.1016/j.patcog.2026.113254) — with the `stoodx` package, a runnable example that needs no dataset, and a test suite.
